## Employee Attendance & Productivity MIS

## 📊 Project Overview

This project is an Employee Attendance & Productivity Management Information System (MIS) created to analyze employee attendance, absenteeism, late arrivals, work-from-home usage, and average working hours.

The project demonstrates practical skills in Microsoft Excel, SQL, Python, and Power BI and is designed as a portfolio project for an entry-level MIS Executive / Data Analyst role.

## 🎯 Objectives


- Monitor employee attendance
- Calculate attendance rate
- Analyze late arrivals and absences
- Compare attendance across departments
- Analyze average working hours
- Track Work From Home (WFH) utilization
- Create management-friendly MIS reports and dashboards

## 🛠️ Tools Used


- Microsoft Excel – Data preparation and MIS summaries
- SQL – Data analysis and reporting queries
- Python – Data analysis and processing
- Power BI – Interactive dashboard and visualization
- GitHub – Project documentation and portfolio
